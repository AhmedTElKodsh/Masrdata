# MasrData RAG planning

This repository contains the draft requirements and delivery estimate for a RAG proof of concept over Egyptian CSV and JSON reports. The first-week POC and month-two MVP focus on single-subject retrieval through a bilingual web UI. The five-month plan extends ingestion, evaluation, and handoff. Cross-dataset questions are outside this POC.

- [Product requirements](./_bmad-output/prd-masrdata-rag-poc/prd-masrdata-rag-poc.md) ([Word version](./_bmad-output/prd-masrdata-rag-poc/prd-masrdata-rag-poc.docx))
- [Delivery and data estimate](./_bmad-output/prd-masrdata-rag-poc/estimate-masrdata-rag-poc.md) ([Word version](./_bmad-output/prd-masrdata-rag-poc/estimate-masrdata-rag-poc.docx))

The `data/` directory currently contains metadata samples only. The client will provide the matching CSV and JSON data files. The `_bmad/` directory contains the local planning setup.
